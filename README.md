# MOBA_3D

第一人称镜头的 3D MOBA。玩法按传统 MOBA：三路兵线、打野、补刀、推塔，摧毁基地获胜。镜头、移动和朝向按第一人称操作。权威模拟在虚幻专用服务器上，登录、组队、匹配和战绩放在局外服务里。

已确认的规则以 [docs/agents/00-orchestrator.md](docs/agents/00-orchestrator.md) 为准。本文件只介绍项目，不另写一套玩法。规则有冲突时，以统筹文件为准。

## 玩法概要

- 两队各 5 人，一张地图。地图按上路 1、中路 1、下路 2、打野 1 设计，不把玩家锁死在某一路。
- WASD 移动，鼠标控制朝向。鼠标左键对准心附近的可见目标发起普通攻击，右键停手。没有弹匣，出手间隔由攻速决定。每个英雄的攻击距离单独配置。
- 第一版英雄模板是战士、法师、射手。战士近身挥击，法师和射手用飞行物。距离不按职业写死。
- 每条路有外塔和内塔，其后是基地。小兵分近战和远程。地图有打野营地和草丛，第一版没有插眼。
- 局内有等级、4 个技能、补刀金币和少量固定物品。具体生命、金币和攻击距离等数字仍是占位，以后再调。

## 架构

一局比赛固定在一个专用服务器进程里。人多了就多开局，不把同一局拆到多台机器上。

```
客户端（虚幻，第一人称）
    |  只提交输入
    v
本机 Windows 专用服务器
    |  结算普攻、兵线、伤害、胜负
    v
局外服务（账号、组队、匹配、战绩）
```

局外服务在两个客户端能进入同一台本机服务器之前不安装。开发期用固定进局口令。之后账号和匹配默认用 Nakama，一台机器不够多开时再加 Agones。对局模拟仍然留在虚幻里。

服务器模拟默认每秒 60 次，写在 `Config/DefaultEngine.ini` 的 `NetServerMaxTickRate`。英雄的网络同步密于小兵、野怪和塔。

## 当前进度

英雄窗口的第一版和四个技能槽已经验收：普通攻击，以及数字键 1 到 4 的命中扫描、飞行物和自身增益。默认英雄是战士，队伍固定为 1 队。

兵线窗口的第一版已经验收：`/Game/Maps/LaneTest` 上有刷兵、外塔、内塔、基地、泉水、打野营地和草丛。命中后的请求先进入本拍列表，再留下最后一条。兵线本身不扣血。

战斗窗口的第一版已经验收：权威端在追加之后结算生命、金币和经验。伤害按配置分为物理、魔法和真实三种。商店出售鞋子、攻击、生命，购买和回血都要在己方泉水旁边。死亡后按对局时间复活，并落到己方泉水。回城有读条，按键还没接上。

同步窗口的第一版已经验收：服务器按队伍视野决定看得见谁。看不见的英雄、兵线单位和普攻飞行物不会发给对应客户端。当前生命、生命上限和金币只复制给英雄所属的连接。

表现窗口的第一版已经验收：小地图只画客户端上已有的英雄和兵线单位。自己的生命和金币在战斗组件到达后显示。

当前没有新的实现窗口。下一步是两个客户端进入同一台本机服务器。局外服务仍用固定进局口令，连接时还不校验这句口令，两个客户端能进同一局之前不安装匹配产品。

## 窗口怎么协作

不同对话窗口分工开发。每个窗口只改自己的进度文件和划给自己的目录。

| 窗口 | 先读 |
| --- | --- |
| 统筹 | [docs/agents/00-orchestrator.md](docs/agents/00-orchestrator.md) |
| 英雄 | [docs/agents/01-hero.md](docs/agents/01-hero.md) |
| 兵线 | [docs/agents/02-lane.md](docs/agents/02-lane.md) |
| 战斗 | [docs/agents/03-combat.md](docs/agents/03-combat.md) |
| 同步 | [docs/agents/04-replication.md](docs/agents/04-replication.md) |
| 表现 | [docs/agents/05-presentation.md](docs/agents/05-presentation.md) |
| 局外 | [docs/agents/06-meta.md](docs/agents/06-meta.md) |

开工前先读统筹文件，再读本窗口的进度文件。模块之间通过公开接口通信：可攻击单位实现 `IAttackable`，攻速和攻击距离从 `ICombatStatSource` 读，命中后提交 `FHeroDamageRequest`。提交时先把这一条放进本拍列表，再覆盖最后一条，然后才结算。不得去掉这次追加。兵线不扣血。草丛只记录谁站在里面，看得见与否由同步窗口的查询回答，复制图按这个结果过滤。

要改 `.uproject`、`Config/`、共享 `Build.cs` 或 `TestGym` 时，先写进自己的进度文件，等统筹窗口登记后再改。

## 打开工程

本机使用的引擎是虚幻 5.8.3，安装路径 `E:\UE_5.8`。用这份引擎打开仓库根目录的 `MOBA.uproject`。

未烹饪的专用服务器不要单独运行 `Binaries\Win64\MOBAServer.exe` 来加载关卡。启动器版引擎没有独立的服务器预编译库，服务器目标按游戏类型编出。开发时用编辑器的 `UnrealEditor.exe` 加上 `-server` 打开关卡，监听 7777。英雄验收用 `/Game/Maps/TestGym`。兵线用自己的 `/Game/Maps/LaneTest`，不要把默认地图改掉。

编辑器里直接 Play，进的是 `TestGym`：一张地板、一个 2 队木桩，自己是 1 队战士。WASD 移动，鼠标转向，左键普攻，右键停手，数字键 1 到 4 放技能。

要看兵线，先另开一个进程当服务器，再开客户端连上去：

```text
E:\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe E:\MOBA_3D\MOBA.uproject /Game/Maps/LaneTest -server -log -port=7777
E:\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe E:\MOBA_3D\MOBA.uproject 127.0.0.1:7777 -game -windowed -log
```

第二个客户端再执行一次上面的客户端命令。连接时还不输入进局口令。出生点在原点附近，兵线在 Y 轴正方向。每个客户端现在都是 1 队，彼此打不到；可以打 2 队的木桩、小兵和塔。商店和回城还没有按键。
