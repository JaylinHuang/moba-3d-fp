# 战斗窗口

状态：三种伤害已验收
最后更新：2026-10-08
职责：服务器上的伤害、护甲、魔抗、攻速、攻击距离、金钱、经验和商店结算。本模块不关心伤害来自普通攻击、技能、塔还是野怪。

玩法细则以 `docs/agents/00-orchestrator.md` 为准。

## 独占目录

代码在 `Source/MOBA/Combat/`。独占范围：

- 伤害请求的接收与结算
- 生命、护甲、魔抗、物理伤害、魔法伤害、真实伤害、攻速、攻击距离
- 金钱、经验、补刀归属、范围内友军共享经验
- 商店里的固定物品与购买校验
- 复活时间随对局推进变长

英雄模块只读取攻速和攻击距离。物品效果改变这些数值时，由本模块写回。

## 禁止修改

- `docs/agents/` 下除本文件以外的进度文件

- 英雄移动、镜头和普通攻击的目标选择
- 兵线路径、刷兵、营地摆放、草丛体积和胜负状态机
- HUD、特效和小地图
- 局外账号与匹配

开工条件：英雄窗口完成虚幻工程和两个编译目标。数值表的字段若要成为跨模块契约，先写进本文件的进度日志，由统筹窗口写入 `docs/contracts/`。
