# 同步窗口

状态：所属连接上的生命和金币已验收
最后更新：2026-10-08
职责：按视线、掩体和草丛决定每个客户端能收到哪些单位，并处理英雄移动的预测校正。小兵、野怪和塔不做全量回滚。

玩法细则以 `docs/agents/00-orchestrator.md` 为准。复制图可以改这三处：`Source/MOBA/MOBA.Build.cs` 只增加 `ReplicationGraph` 依赖，`MOBA.uproject` 只启用该插件，`Config/DefaultEngine.ini` 只把复制图类接到网络驱动。默认地图、游戏模式和模拟次数不改。

## 独占目录

独占范围：

- `Source/MOBA/Vision/`：占位视野配置、世界视野状态、复制图
- `Source/MOBA/HeroVisibilityQuery.cpp`：查询转发到世界视野状态。兵线验收时已把这份实现留给本窗口
- 视线、掩体和草丛的可见性判定
- 复制相关性：不可见单位不发给该客户端
- 草丛中攻击或受伤后的短暂显形
- 英雄移动和普通攻击命令的预测校正。这一项不在当前计划里
- 小兵、野怪、塔、飞行物的服务器模拟与客户端插值策略。同步频率不在当前计划里

草丛体积由兵线窗口摆放。本窗口只判断一个单位此刻是否可见，调用现有的 `ALaneBrush::Contains`。

## 当前计划

自己的当前生命、生命上限和金币已只复制给英雄所属的连接。组件会出现在该客户端上。结算公式没改。预测校正和同步频率仍留在后面。

统筹窗口已补记队伍视野。复制图的三处共享文件已登记，可以做任务 5.1 和 5.2。

筹划在 OpenSpec 变更 `team-vision`。待办如下，细节以该变更的 proposal、design、specs 和 tasks 为准。

1. 个人视线看三件事：占位水平视野距离、草丛、抬高后只打世界静态物的视线。单位不挡视线。占位初值是视野距离 1500、显形 1 秒、视线抬高 50，放在 `Source/MOBA/Vision/`，不写进规则。
2. 队伍视野等于任一存活的己方英雄、近战小兵、远程小兵、外塔、内塔或基地看得见。野怪不提供视野，死亡单位不再提供。己方单位对本队始终可见，包括在草丛中。`IsVisibleTo` 返回这份队伍视野，英雄和兵线的两份查询读同一份世界状态。
3. 草丛中出手或在草丛中受伤时，该单位对敌方整队显形。近战、小兵和塔读本帧伤害流水。飞行物在生成时观察来源，不改英雄普攻。显形期间该单位和这发飞行物对敌方整队可见。
4. 复制图只过滤英雄、兵线单位和飞行物。己方始终发送，敌方要队伍看得见才发送。看不见的单位不在客户端留最后位置。`Build.cs`、`.uproject` 和 `Config/DefaultEngine.ini` 里启用复制图的改动已登记。
5. 预测校正和同步频率仍留在本窗口的后续计划，不进 `team-vision`。
