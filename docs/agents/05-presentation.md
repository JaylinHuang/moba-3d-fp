# 表现窗口

状态：第一版已验收
最后更新：2026-10-06
职责：HUD、特效、音效，以及不改变权威状态的界面镜头效果。只读取已经复制到客户端的状态。

## 独占目录

- `Source/MOBA/Presentation/`：小地图和自己英雄的生命、金币

落地后的其余独占范围：

- 对局 HUD、商店界面、结算界面
- 枪口、受击、技能的客户端特效和音效
- 界面层的镜头抖动等纯表现效果

英雄 Pawn 上的第一人称相机挂载属于英雄窗口。本窗口不改 Pawn 的移动和输入。

## 禁止修改

- `docs/agents/` 下除本文件以外的进度文件
- `docs/contracts/`
- 服务器结算、兵线状态机、伤害公式
- 专用服务器的权威逻辑
- 局外匹配与账号

## 依赖契约

无跨模块写入契约。表现依赖复制到客户端的只读状态。若某个状态没有被复制，在本文件记录缺口，由同步窗口或统筹窗口处理。

开工条件：客户端上能看到已复制的英雄或单位。

## 当前计划

1. 同步第一版已验收。客户端只会收到队伍看得见的英雄、兵线单位和飞行物。小地图只画这些已复制的单位：位置、队伍、种类、死活。
2. HUD 和上一件同一次做。只读所属客户端上自己这名英雄的当前生命、生命上限和金币。组件还不在客户端时，生命和金币留空，不用 0 冒充已经同步。别人头上的血条和别人的金币这一刀不画。
3. 受击和开火特效仍在计划里，不进这一刀，也不参与结算。

缺口，由同步窗口或统筹窗口处理。表现窗口不改 `Source/MOBA/Combat/`。

`UCombatStateComponent` 只由权威端的 `UCombatResolutionSubsystem::EnsureState` 创建。客户端上的结算直接返回，组件不会出现在客户端。`Health`、`MaxHealth`、`Gold` 也没有复制。需要把这三个数复制到这名英雄所属的连接。金币不发给其它连接。这一刀的生命和上限也同样只发给本人。

屏幕上的挂钩这一刀不登记。画布回调放在 `Source/MOBA/Presentation/`，不改 `AMOBAGameMode` 和 `MOBA.Build.cs`。以后若要 UMG，再向统筹登记 `Build.cs`。
