# 局外窗口

状态：未开始
最后更新：2026-10-05
职责：登录、组队、匹配、为对局分配专用服务器、接收战绩。本窗口不包含对局内模拟。

## 独占目录

- 局外服务进程及其配置。进程技术选型尚未拍板，目录名等选型后写入本文件
- 进局流程：把令牌和服务器地址交给客户端
- 战绩存储与查询

虚幻专用服务器进程不属于本窗口。本窗口只与它交换令牌和对局结果。

## 禁止修改

- `docs/agents/` 下除本文件以外的进度文件
- `docs/contracts/`
- 英雄、兵线、战斗、同步、表现的实现
- 对局内的伤害、金钱和胜负判定

## 依赖契约

- 进局令牌：发给客户端和专用服务器，契约尚未编写
- 对局结果：从专用服务器接收，契约尚未编写

Nakama、Agones、Open Match 仍是参照，不是已指定依赖。选型写进进度日志后，由统筹窗口确认。

## 当前计划

1. 在契约落地前，用文档描述进局和回写流程，不先绑定具体产品。
2. 选型确认后实现令牌签发。
3. 接收基地被摧毁后的对局结果并保存战绩。
